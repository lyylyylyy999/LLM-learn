# 正式任务

本目录保存正式编码任务。每个任务使用 `TASK-XXX-short-description.md` 命名，并从[任务模板](templates/task-template.md)创建。

## 任务生命周期

1. **待确认**：导师根据路线图和最近证据提出任务、难度、预计时间及建议分支名。
2. **进行中**：学习者确认任务，并决定是否从 `develop` 创建 `learn/task-XXX-short-description`。
3. **代码审查**：学习者完成自测，请求基于任务分支与 `develop` 差异的代码审查。
4. **修改中**：学习者根据审查发现修复和补测；代码审查与修改可以重复多轮。
5. **最终审查**：代码满足验收标准后，导师根据最终实现提出 3–5 个针对性问题。
6. **已完成**：导师基于审查证据起草本次所学和关键错误，学习者核对补充并回答针对性问题；双方共同完成对应难度的复盘，满足任务完成定义，并获得建议提交信息。

一个任务聚焦一个主要学习目标，预计有效编码时间通常为 30 分钟到 3 小时。复杂功能应拆分，不在任务进行中悄悄扩大范围。

目录中的任务文件记录稳定需求和验收条件；实现代码放在相应的 `exercises/` 或 `projects/` 子目录中，这些目录在首次需要时再创建。
