# 任务复盘模板

## 使用说明

- L1/L2 任务使用简版，控制在 5–10 分钟。
- L3/L4/L5 任务使用完整版。
- 导师根据 diff、测试和审查记录起草本次所学、关键错误、根因和工程经验；学习者核对并补充。
- 学习者负责回答用于检验理解的最终审查问题，导师可以评阅和追问，但不直接代答。
- 问题来自代码通过最终审查之后，由导师根据最终实现和修改过程提出。
- 问题回答可以作为复盘主体，不要求写成长文。
- 删除未使用的模板部分，不保留占位文字。
- 任务复盘不记录下一步行动；完成复盘后直接进入下一个任务。
